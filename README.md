# Projet de fin d'annee - M1 LDFS (2025-2026)

## Presentation

Ce projet consiste a concevoir et developper une application de suivi de la Coupe du monde FIFA 2026.
L'objectif est de proposer une application (web, mobile ou hybride) permettant de consulter les matchs, suivre les scores et visualiser l'evolution de la competition en temps reel.
